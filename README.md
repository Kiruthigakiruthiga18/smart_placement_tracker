
# Student Placement Management System

A web-based Student Placement Management System designed to help students manage their placement preparation and job search activities in one platform.

## Features

- Student profile management
- Skills management
- Skill assessment
- Resume preview
- Job recommendations
- Job application tracking
- Interview tracking
- Placement preparation roadmap
- Placement goals management
- Notifications
- Placement analytics
- Light and dark mode support

## Technologies Used

- HTML5
- CSS3
- JavaScript
- LocalStorage
- Netlify

## Project Purpose

The main purpose of this project is to simplify the placement preparation process by allowing students to maintain their personal information, skills, applications, interviews, and career goals in one centralized web application.
